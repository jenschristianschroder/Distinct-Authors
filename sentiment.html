Subreddit Sentiment & Opinion Analysis

Search Reddit semantically with OpenAI web search, fetch discovered Reddit threads directly when possible, backfill with Arctic Shift, then analyze sentiment, opinions, voices, time, and post popularity.

How retrieval works
OpenAI searches Reddit from multiple lexical and semantic angles. The backend then tries to fetch discovered Reddit threads directly and runs Arctic Shift searches using AI-generated topic variants. Results are deduplicated before analytics. This improves coverage, especially for recent discussion, but cannot guarantee every Reddit post or comment.
AI search connection

The OpenAI API key stays server-side on Vercel. The backend URL may be remembered locally; the access token is kept only for this browser tab.

Retrieval log & web sources
Retrieval combines OpenAI web search restricted to Reddit, best-effort direct Reddit thread fetching, and Arctic Shift archive backfill. Coverage is intentionally broad but not exhaustive. Sentiment labels are lightweight local heuristics; the opinion summary is generated by OpenAI from the retrieved sample.
